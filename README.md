One funny line, written by a program, for make.fun's "The One-Line Laugh" bounty: a single sentence of at most 200 characters on any subject, judged two at a time by the house judge.

## Run it

```sh
python3 main.py
```

The program writes one line to `/output/entry.txt` (87 characters, UTF-8, no trailing newline). Deterministic: two runs from a clean copy produce byte-identical output. No network, no dependencies, no files outside this repository.

## The line

> The IKEA Allen key and I have built three bookshelves, two bed frames, and one divorce.
